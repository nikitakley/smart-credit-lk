# Бэкенд

FastAPI-приложение: API личного кабинета, кредитный конвейер, скоринг.

> **Этап 1.** Все эндпоинты контракта работают на заглушках в памяти (`app/stubs/`).
> Данные сбрасываются при перезапуске или через `POST /api/demo/reset`. Конвейер обработки не запущен:
> отправленная заявка остаётся в статусе `submitted`.

## Локальный запуск без Docker

Нужен [uv](https://docs.astral.sh/uv/) и Python 3.12 (`uv python install 3.12`).

```bash
cd backend
uv sync                                        # зависимости из uv.lock
uv run uvicorn app.main:app --reload           # http://localhost:8000/api/docs
uv run pytest                                  # тесты
uv run python scripts/export_openapi.py        # обновить docs/api/openapi.json
```

## Структура

```
app/
├── main.py           # создание приложения, подключение роутеров
├── config.py         # настройки из переменных окружения
├── errors.py         # единый формат ошибок
├── security.py       # JWT и проверка ролей
├── schemas/          # модели запросов и ответов (контракт API)
├── services/         # бизнес-логика: подбор продукта, финансовые расчёты
├── api/routes/       # эндпоинты
└── stubs/            # ВРЕМЕННЫЕ демо-данные и хранилище в памяти (этап 1)
```

## Зависимости

Версии зафиксированы в `uv.lock`. Добавить пакет: `uv add <пакет>` (для разработки — `uv add --dev <пакет>`).
Lock-файл коммитится вместе с `pyproject.toml`.
